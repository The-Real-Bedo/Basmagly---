# بصمجّلي شكرًا | Basmagly 🎓⚡

منصة دراسية ذكية وشاملة لمقررات وعلوم الحاسب لطلاب الجامعات، تركز على تقديم زتونة المنهج للامتحان من غير حشو، مدعومة بمعامل تفاعلية بصرية، ملخصات مركزة، وبنك أسئلة مطابق لأنماط امتحانات الكلية.

---

## ✨ المميزات الرئيسية

- **زتونة المحاضرات:** تلخيص مكثف مع الشرح ببساطة ومن الآخر وقواعد الامتحان الذهبية (High-Yield Rules).
- **معامل تفاعلية متطورة (Interactive Labs):**
  - **Network Devices & Collision Domain:** محاكاة الفرق بين Hub و Switch و Router.
  - **Packet Journey:** تتبع رحلة الحزمة ونطة الراوتر وثبات الـ IP وتغير الـ MAC.
  - **OSI 7 Layers vs TCP/IP:** محاكاة التغليف (Encapsulation).
  - **IPv4 Subnet Calculator:** حسابات الـ CIDR والـ Subnetting بالوحايد والأصفار.
  - **Edge vs Cloud Computing:** محاكاة استجابة الطوارئ وسرعة الـ Latency.
  - **IoT Pipeline Simulator:** محاكي الدورة الرباعية لإنترنت الأشياء.
  - **Vacuum World Agent & PEAS:** محاكي الوكيل العقلاني ومصفوفة PEAS.
  - **Alan Turing Test:** محاكي اختبار تورينج والتخصصات الستة للذكاء الاصطناعي.
  - **Network Topologies:** معمل قطع الكابلات واختبار الـ Bus والـ Star والـ Ring والـ Mesh.
  - **Transmission Modes:** تجربة الفرق بين Unicast و Broadcast و Multicast.
- **بنك أسئلة وتدريب امتحانات:** أسئلة MCQ، صح وخطأ، وأسئلة مقالية بإجابات نموذجية معتمدة.
- **تصميم هادئ ومريح للعين:** دعم الوضع الداكن (Dark Mode) ووضع البيج الخفيف (Warm Soft Beige) المتوافق مع معايير الـ WCAG AA.
- **تايبوجرافي عربي متخصص:** معالجة دقيقة لاتجاه النصوص المختلطة (RTL/LTR) وعزل المصطلحات الإنجليزية لضمان عدم قفز علامات الترقيم.

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الحزم:**
```bash
npm install
```

2. **تشغيل سيرفر التطوير:**
```bash
npm run dev
```

3. **بناء المشروع للإنتاج:**
```bash
npm run build
```
